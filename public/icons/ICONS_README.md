# Iconos PWA necesarios

Para la instalación como PWA en móvil y escritorio, necesitas 2 archivos PNG:

- `icon-192.png` (192x192 px)
- `icon-512.png` (512x512 px)

## Cómo generarlos gratis

1. Ve a https://favicon.io/favicon-generator/
2. Texto: "IK"  |  Color fondo: #3B82F6  |  Color texto: Blanco  |  Forma: Redondeada
3. Descarga y renombra los PNGs a icon-192.png y icon-512.png
4. Colócalos en esta carpeta

## Alternativa (conversión desde el SVG)

Puedes convertir el icon.svg incluido en esta carpeta usando:
- https://svgtopng.com/
- Tamaños: 192x192 y 512x512
